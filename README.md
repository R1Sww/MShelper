# MSHelper - MasterSCADA Helper v5.0

Десктопное приложение для удобной работы со всеми версиями MasterSCADA с полной функциональностью.

## Структура проекта

```
MSHelper/
├── MSHelper.exe          # Готовая версия для Windows
├── masterscada_helper.py # Исходный код
├── MSHelper.spec         # Конфигурация сборки PyInstaller
├── requirements.txt      # Зависимости Python
└── README.md             # Документация
```

## Портативность

Приложение полностью портативно:
- Все данные хранятся в папке `data` рядом с .exe файлом
- Можно скопировать всю папку MSHelper на другой ПК
- Не требует установки Python или других зависимостей
- Работает на ПК с Windows

Папка `data` создаётся автоматически при первом запуске. Пользовательские настройки, история и статистика хранятся локально и не входят в репозиторий.
## Поддерживаемые версии

- **MasterSCADA 4.0**
- **MasterSCADA 4.1**
- **MasterSCADA 4.2**
- **MasterSCADA 4D**
- **MasterSCADA 3.x**
- **И другие версии**

## Возможности

### Основные
- **Автоматическая вставка в MasterSCADA** — приложение само находит окно MasterSCADA и вставляет выбранный элемент
- **Автоматическое сканирование MasterSCADA** — приложение само находит установленную версию MasterSCADA на ПК и извлекает все данные
- **Сортировка по алфавиту** — все элементы автоматически сортируются по алфавиту в своих категориях
- **Категоризированный список элементов** — теги, команды, типы данных, устройства, события, шаблоны скриптов
- **Быстрый поиск** — мгновенный поиск по всем элементам базы
- **Копирование в буфер обмена** — двойной клик или кнопка для быстрой вставки в MasterSCADA
- **Редактирование базы** — добавление своих категорий и элементов
- **Экспорт/импорт** — сохранение и загрузка базы данных

### Избранное
- **Добавление в избранное** — помечайте часто используемые элементы звёздочкой
- **Быстрый доступ** — отдельное окно избранного для быстрой вставки
- **Контекстное меню** — правый клик для добавления/удаления из избранного

### Горячие клавиши
- **F1-F12** — назначение горячих клавиш для мгновенной вставки
- **Настройка клавиш** — удобный интерфейс для назначения клавиш
- **Автоматическая вставка** — при нажатии клавиши элемент автоматически вставляется в MasterSCADA

### Пакетная вставка
- **Выбор нескольких элементов** — выделите несколько элементов для одновременной вставки
- **Настраиваемый разделитель** — выберите разделитель между элементами (новая строка, запятая и т.д.)
- **Быстрая вставка** — все выбранные элементы вставляются одним действием

### Шаблоны проектов
- **Создание шаблонов** — сохраняйте наборы элементов для типовых проектов
- **Применение шаблонов** — быстрая вставка всех элементов шаблона
- **Просмотр шаблонов** — просмотр содержимого шаблона перед применением
- **Управление шаблонами** — создание, просмотр, применение и удаление шаблонов

### История и статистика
- **История операций** — журнал всех вставок и копирований
- **Повторное использование** — копирование из истории одним кликом
- **Статистика использования** — подсчёт частоты использования элементов
- **Топ элементов** — просмотр наиболее часто используемых элементов

### Системные функции
- **Минимизация в трей** — сворачивание в системный трей при закрытии
- **Автозапуск** — запуск приложения при старте Windows
- **Резервное копирование** — автоматическое резервное копирование всех данных
- **Экспорт в текстовый файл** — экспорт выбранных элементов в .txt файл

## Запуск

### Вариант 1: Готовый .exe файл (рекомендуется)

Просто запустите файл:
```
MSHelper.exe
```

### Вариант 2: Запуск из исходного кода (Windows)

1. Установите Python 3.10 или новее с [python.org](https://python.org)
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите:
   ```bash
   python masterscada_helper.py
   ```

### Сборка .exe

Чтобы пересобрать приложение из исходного кода, установите зависимости и PyInstaller, затем выполните:

```bash
pip install -r requirements.txt
pip install pyinstaller
pyinstaller --clean --noconfirm MSHelper.spec
```

Готовый файл появится в папке `dist`.

## Использование

### Первый запуск

1. Запустите MSHelper.exe
2. Нажмите кнопку **"🔄 Сканировать MasterSCADA"** в верхней панели
3. Приложение автоматически найдёт установленную версию MasterSCADA на вашем ПК
4. Все данные из проекта будут извлечены и отсортированы по алфавиту в категориях

### Автоматическая вставка в MasterSCADA

1. **Запустите MasterSCADA** и откройте нужный проект
2. В приложении выберите нужный элемент из списка
3. Нажмите **"📥 Вставить"** или сделайте **двойной клик** на элементе
4. Приложение автоматически:
   - Найдёт окно MasterSCADA
   - Активирует его
   - Вставит выбранный элемент

### Избранное

1. Выберите элемент в списке
2. Нажмите **"⭐ В избранное"** или правый клик → "Добавить в избранное"
3. Для просмотра избранного: меню **"Избранное" → "Показать избранное"**
4. В окне избранного можно быстро вставлять элементы

### Горячие клавиши

1. Выберите элемент и нажмите **"⌨️ Назначить клавишу"**
2. Выберите клавишу F1-F12
3. Теперь при нажатии этой клавиши элемент будет автоматически вставляться в MasterSCADA

### Пакетная вставка

1. Выберите несколько элементов (Ctrl+клик или Shift+клик)
2. Нажмите **"📦 Пакетная"** или `Ctrl+B`
3. Выберите разделитель между элементами
4. Все выбранные элементы будут вставлены в MasterSCADA одним действием

### Шаблоны проектов

1. Выберите несколько элементов
2. Меню **"Шаблоны" → "Создать шаблон"**
3. Введите название шаблона
4. Для применения: меню **"Шаблоны" → "Применить шаблон"** или `Ctrl+T`

### История и статистика

- **История**: меню **"История" → "Показать историю"** или `Ctrl+H`
- **Статистика**: меню **"Статистика" → "Показать статистику"**

### Выбор версии MasterSCADA

1. Перейдите в меню **"Вставка" → "Версия MasterSCADA"**
2. Выберите нужную версию:
   - MasterSCADA 4.0
   - MasterSCADA 4.1
   - MasterSCADA 4.2
   - MasterSCADA 4D
   - MasterSCADA 3.x
   - MasterSCADA (любая версия)

### Настройки

- **Настройки вставки**: меню **"Вставка" → "Настройки вставки"**
  - Заголовок окна MasterSCADA
  - Режим поиска (содержит/точное совпадение)
  - Автоматическая вставка при двойном клике
  - Минимизация в трей

- **Настройки автозапуска**: меню **"Настройки" → "Настройки автозапуска"**
  - Запуск при старте Windows

- **Настройки резервного копирования**: меню **"Настройки" → "Настройки резервного копирования"**
  - Включение/выключение
  - Интервал копирования (в часах)

## Горячие клавиши

- `Ctrl+F` - фокус на поле поиска
- `Ctrl+C` - копировать выбранный элемент
- `Ctrl+I` - вставить в MasterSCADA
- `Ctrl+B` - пакетная вставка
- `Ctrl+T` - показать шаблоны
- `Ctrl+H` - показать историю
- `Ctrl+S` - сканировать MasterSCADA
- `Ctrl+Q` - выход из программы
- `F1-F12` - вставка элементов с назначенными клавишами
- Двойной клик - вставить в MasterSCADA
- Правый клик - контекстное меню

## Перенос на другой ПК

1. Скачайте ZIP-архив репозитория через GitHub (**Code → Download ZIP**) или клонируйте репозиторий.
2. Запустите `MSHelper.exe` на ПК с Windows.
3. При первом запуске приложение создаст папку `data`; пользовательские настройки, избранное, история и шаблоны будут сохраняться на этом ПК.

Для переноса пользовательских данных между ПК отдельно скопируйте папку `data`.

## Совместимость

Приложение совместимо со всеми версиями MasterSCADA, так как использует:
- Буфер обмена для передачи данных
- Windows API для поиска и активации окон
- Универсальный метод вставки (Ctrl+V)
- Гибкий поиск окна по части заголовка
